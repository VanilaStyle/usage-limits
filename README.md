# usage-limits

Мод для Claude Code. Показывает шкалы 5-часового и недельного лимита подписки (Pro/Max): процент использования, время до сброса, токены текущей сессии и примерную оценку лимита в токенах.

- **Панель «Лимиты»**: в полноэкранном терминале шириной от 110 колонок она закреплена справа от переписки, в узком окне показывается над полем ввода.
- **Строка состояния** под полем ввода с обеими шкалами.
- **Команда `/limits`** открывает панель и выводит цифры текстом.

Проценты присылает сервер. Лимиты в токенах нигде не публикуются, поэтому токены (≈) — это оценка: мод сравнивает, сколько токенов потратила сессия и на сколько за это время сдвинулся процент. Оценка появляется после сдвига шкалы хотя бы на 1%; параллельные сессии делают её завышенной.

## Установка

В терминальной сессии Claude Code:

```
/plugin install usage-limits --marketplace VanilaStyle/usage-limits
```

Из командной строки:

```bash
claude plugin install usage-limits --marketplace VanilaStyle/usage-limits
```

На вопрос `Add marketplace?` ответьте `y`, затем выберите область установки (Enter — для пользователя).

В десктоп-приложении, где `/plugin` недоступна: нажмите + рядом с полем ввода → Plugins → Add marketplace с `VanilaStyle/usage-limits` → Add plugin.
